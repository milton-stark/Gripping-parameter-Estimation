# Contributing

Thanks for your interest in contributing to Gripping Parameter Estimation. Please follow these guidelines:

- Fork the repository and create a feature branch for your changes.
- Keep changes small and focused; include tests or reproducible examples where applicable.
- Write clear commit messages in the conventional commits style (e.g., `feat:`, `fix:`, `docs:`, `chore:`).
- Run `python -m py_compile` on changed Python files before opening a PR.
- If adding datasets or large binaries, place them under `data/` or `docs/` and avoid committing unnecessarily large files to the main history.

Open a PR against `main` and describe the motivation and testing performed. Expect review feedback and be prepared to iterate.
